# Pagelea support

## Community support

Use the repository's issue templates for reproducible bugs and feature
requests. Before opening an issue:

- search for an existing report;
- reproduce with the latest supported revision;
- remove document contents, filenames, personal data, tokens, and secrets;
- create the smallest synthetic PDF that demonstrates the problem;
- include operating system, browser, Pagelea version or commit, and exact
  reproduction steps.

Community support is best effort. There is no guaranteed response or
resolution time.

## Security reports

Do not report vulnerabilities in a public issue. Follow
[SECURITY.md](SECURITY.md) and use GitHub's private vulnerability reporting
for this repository.

## Privacy and document recovery

Pagelea's document tools operate in browser memory and do not provide a server
document library. Maintainers cannot recover a source file, an unsaved edit,
or a local download.

Never attach a confidential PDF to a public issue. Recreate the problem using
synthetic data.
